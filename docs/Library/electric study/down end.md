## 二、分析计算题（本题满分 80分）

**1. 单相桥式整流电路，已知交流电网电压为 220V，负载电阻 $R_L = 50\Omega$，负载电压 $U_o=100V$，试选择二极管。（10分）**

* **解：**
    1.  流过二极管的平均电流：$I_D = \frac{1}{2} \cdot \frac{U_o}{R_L} = \frac{1}{2} \cdot \frac{100}{50} = \mathbf{1A}$
    2.  二极管承受的最大反向电压：$U_{DRM} = \sqrt{2}U_2 \approx 1.57U_o = 1.57 \times 100 = \mathbf{157V}$
    3.  选型：应选择 **额定电流 $I_F \ge 1A$，反向击穿电压 $U_R \ge 157V$** 的整流二极管。

**2. 图示为硅三极管在工作时实测的各极对地电压值。试根据各极对地电压判断三极管类型及工作状态。（10分）**

* **(a)** $U_B=1.7V, U_C=1.3V, U_E=1V$：**NPN型，饱和状态**
    *(解析: $U_{BE}=0.7V$导通, $U_{CE}=0.3V < U_{BE}$)*
* **(b)** $U_B=0.7V, U_C=3V, U_E=0V$：**NPN型，放大状态**
    *(解析: $U_{BE}=0.7V$导通, $U_{CE}=3V$)*
* **(c)** $U_B=0.5V, U_C=6V, U_E=1.5V$：**NPN型，截止状态**
    *(解析: $U_{BE}=-1V$反偏)*
* **(d)** $U_B=-1.7V, U_C=-3V, U_E=-1V$：**PNP型，放大状态**
    *(解析: $U_{EB}=0.7V$导通, $U_{EC}=2V$)*

**3. 如下图所示放大电路中，已知 $U_{CC}=15V, R_B=500k\Omega, R_C=5k\Omega, R_L=5k\Omega, \beta=50$。（1）求静态工作点；（2）画出微变等效电路；（3）求 $A_u, r_i, r_o$。（10分）**

* **解：**
    * (1) **静态工作点：**
        $I_{BQ} = \frac{U_{CC}-U_{BE}}{R_B} \approx \frac{15}{500k} = \mathbf{30\mu A}$
        $I_{CQ} = \beta I_{BQ} = 50 \times 0.03mA = \mathbf{1.5mA}$
        $U_{CEQ} = U_{CC} - I_{CQ}R_C = 15 - 1.5 \times 5 = \mathbf{7.5V}$
    * (2) **微变等效电路：** (此处略，需作图)
    * (3) **动态参数：**
        $r_{be} \approx 200 + (1+\beta)\frac{26mV}{I_{EQ}} \approx \mathbf{1.1k\Omega}$
        $A_u = -\frac{\beta(R_C // R_L)}{r_{be}} = -\frac{50 \times 2.5k}{1.1k} \approx \mathbf{-114}$
        $r_i = R_B // r_{be} \approx \mathbf{1.1k\Omega}$
        $r_o = R_C = \mathbf{5k\Omega}$

**4. 试用理想运算放大器设计一个测量系统的输出电压为：$u_o = - (2u_{i1} + 5u_{i2} + 10u_{i3})$。（10分）**

* **解：**
    采用反相加法电路。设反馈电阻 **$R_f = 100k\Omega$**。
    则输入电阻分别为：
    **$R_1 = R_f / 2 = 50k\Omega$**
    **$R_2 = R_f / 5 = 20k\Omega$**
    **$R_3 = R_f / 10 = 10k\Omega$**
    平衡电阻 **$R_p = R_1 // R_2 // R_3 // R_f \approx 5.3k\Omega$**

**7. 设计一个激光射击游戏中，允许射手在规定时间内打三枪，这三枪必须一枪打飞机，一枪打坦克，一枪打汽车。游戏获奖条件：命中不少于两枪，且其中必须有一枪命中的是飞机。试用与非门设计判别获奖的电路。（20分）**

* **解：**
    设 A=飞机, B=坦克, C=汽车 (1=命中, 0=未中)。F=获奖。
    逻辑表达式： **$F = A(B+C) = AB + AC$**
    化简为与非门形式： **$F = \overline{\overline{AB} \cdot \overline{AC}}$**
